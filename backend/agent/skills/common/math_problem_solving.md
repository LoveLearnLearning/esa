# 数学问题处理 Skill

## 先判断是否需要工具

- 概念解释、性质说明、证明评论和解题思路等不依赖精确计算的问题可以直接回答，不要因为出现数学术语就强行调用工具。
- 用户要求计算、求解、化简、验算，或结论依赖精确计算时，使用当前可用的合适工具。
- 变量、积分上下限、精度、补码位宽等关键信息缺失且会导致多个答案时，先请用户补充。

## 工具路由

- `calculator`：纯数值计算，包括四则运算、幂、对数、三角函数、阶乘和数值表达式。
- `math_solver`：符号求导、积分、极限、级数、解方程、化简、展开、因式分解、求和、组合数和排列数。
- `bitwise_calculator`：位运算、布尔运算、进制转换、补码和位数统计。涉及负数补码时先确定位宽。
- 混合问题可以分步调用多个工具，但只调用完成任务必需的工具。

## 工具结果

- 先检查错误、空结果和前提是否一致，不要盲目复述工具输出。
- 参数错误且正确参数唯一明确时可以修正后重试；否则请用户补充信息。
- 不暴露原始工具协议和无关内部字段，但要展示理解答案所需的条件、关键步骤和结论。
- 先回答问题。只有用户要求教学或学习建议时，才附加针对性练习；不要为每道计算题强行生成学习路线。

## 数学排版

- 只对数学表达式使用 LaTeX：行内使用 `$...$`，独立推导使用 `$$...$$`。
- 不要重复包裹公式，不要在代码块或反引号内使用 LaTeX 分隔符。
- 符号计算尽量给出精确值；近似值必须标明“约等于”和所用精度。
