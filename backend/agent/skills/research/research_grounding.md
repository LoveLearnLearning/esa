# 科研内容溯源

## 1. 触发条件
用户请求验证信息来源、区分事实与推断、溯源分析结论或评估内容可靠性时触发。

## 2. 内容分类框架
### 2.1 检索事实
- **定义**：从可靠来源直接检索到的原始信息
- **来源**：学术文献、权威数据库、官方统计
- **特征**：可追溯、可验证、有明确出处
- **处理**：标注来源、提供引用、保留原始表述

### 2.2 分析结论
- **定义**：基于数据或事实通过分析方法得出的推断
- **来源**：统计分析、模型预测、逻辑推理
- **特征**：依赖方法、有置信度、受数据质量影响
- **处理**：说明方法、提供证据、标注置信度

### 2.3 生成内容
- **定义**：AI基于上下文生成的文本、建议或解释
- **来源**：模型推理、模式匹配、知识综合
- **特征**：非直接检索、可能有创造性、需人工审核
- **处理**：明确标注为AI生成、提供推理依据、建议验证

## 3. RAG/附件协作
### 3.1 RAG检索结果处理
1. **来源标注**：记录检索来源（公共库/个人库）
2. **相关性评估**：评估检索结果与问题的匹配度
3. **可靠性分级**：区分同行评审文献、预印本、技术报告
4. **冲突处理**：当检索结果冲突时，注明来源并分析原因

### 3.2 附件内容处理
1. **内容识别**：识别附件类型（论文/数据/代码/文档）
2. **信息提取**：提取关键事实、数据、结论
3. **来源关联**：将附件内容与检索结果关联
4. **边界说明**：说明附件内容的适用范围和限制

## 4. 溯源流程
1. **内容识别**：识别待溯源内容的类型
2. **来源检索**：调用 `retrieve_knowledge` 检索相关来源
3. **证据匹配**：将内容与检索结果匹配
4. **分类标注**：按框架分类并标注
5. **可靠性评估**：评估来源和推理的可靠性

## 5. 输出规范
```text
【内容分类】
- 检索事实：[内容] - 来源：[来源]
- 分析结论：[内容] - 方法：[方法] - 置信度：[置信度]
- 生成内容：[内容] - 推理依据：[依据]

【来源追溯】
主要来源：[来源列表]
可靠性评估：[评估]

【边界说明】
适用范围：[范围]
限制条件：[限制]
建议验证：[验证建议]
```

## 6. 可靠性评估标准
### 6.1 来源可靠性
- **高**：同行评审期刊、权威机构报告、官方统计数据
- **中**：预印本、技术报告、会议论文
- **低**：个人博客、社交媒体、未验证来源

### 6.2 推理可靠性
- **高**：基于充分数据、方法严谨、结论稳健
- **中**：数据有限、方法合理、结论有不确定性
- **低**：数据不足、方法有缺陷、结论推测性强

## 7. 禁止事项
- 不得混淆检索事实和生成内容
- 不得隐藏内容的不确定性
- 不得伪造来源或引用
- 不得忽略冲突的证据
- 不得过度自信地评估可靠性
- 不得跳过边界说明
