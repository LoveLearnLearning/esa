# 掌握度报告 Skill

当用户询问掌握度、学习情况、学情、或学习进度时，按照以下步骤执行。

## 步骤

### 1. 确认查询范围

- 询问用户想要查看的课程（如"数据结构"、"操作系统"），未指定则返回全部课程数据
- 如用户提及具体知识点，直接调用 `get_mastery_level` 获取该知识点掌握度

### 2. 调用报告工具

调用 `get_mastery_report(course)` 获取掌握度报告。

### 3. 输出报告

按以下格式组织报告内容：

```
【掌握度报告】课程名
知识点总数: X
平均掌握度: XX

薄弱知识点（掌握度最低）:
1. 知识点名 - 掌握度 XX - 已练习 X 次 - 上次练习 X 天前
2. ...

掌握较好知识点（掌握度最高）:
1. 知识点名 - 掌握度 XX - 已练习 X 次
2. ...

超过 7 天未练习:
1. 知识点名 - 掌握度 XX - 已 X 天未练习
2. ...
```

### 4. 结合知识图谱补充分析

- 对薄弱知识点，说明其前置依赖关系（如"XX 的前置知识点 YY 掌握度也不高"）
- 对超过 7 天未练习的知识点，提醒用户及时复习
- 可根据掌握度档位给出学习建议：
  - 掌握度 < 40：建议从基础概念开始系统学习
  - 40-75：建议重点练习易错题型
  - >= 75：建议进行进阶综合练习
