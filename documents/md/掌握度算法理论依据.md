## 二、衰减算法

### 2.1 理论依据

**Ebbinghaus 遗忘曲线**（1885）：记忆保持率随时间呈**指数衰减**：

$$R = e^{-\Delta/S}$$

其中：
- $R$ = 保持率（0-1）
- $\Delta$ = 距上次学习的时间
- $S$ = 记忆强度（stability）

**关键特性**：$S$ 不是常数，而是随**练习次数**增长——练得越多，忘得越慢。这与 Murre & Dros (2015) 的复现实验一致。

**HLR 模型**（Settles & Meeder, 2016，Duolingo 采用）：用半衰期 $h = S \cdot \ln 2$ 表征记忆稳定性，通过特征向量估计 $h$。

### 2.2 本项目实现

```python
# 记忆稳定性：基础值 + 练习次数因子
stability = BASE_STABILITY * (1 + PRACTICE_FACTOR * practice_count)
# BASE_STABILITY = 5.0 天, PRACTICE_FACTOR = 2.0

# 指数衰减
retention = exp(-days / stability)
decayed_mastery = mastery * retention
```

**参数选择依据**：
- `BASE_STABILITY = 5.0`：初次学习后约 5 天衰减到 1/e ≈ 37%，符合 Ebbinghaus 原始实验"6 天后遗忘 75%"的量级
- `PRACTICE_FACTOR = 2.0`：每次练习使稳定性增加 2 天，模拟间隔重复效应

### 2.3 验证结果

| 场景 | 练习次数 | 10 天后保持率 | 衰减比例 |
|------|---------|-------------|---------|
| 初次学习 | 1 | 51.42 → 46.75 | 9.1% |
| 多次练习 | 10 | 50.15 → 25.75 | 48.7% |

**结论**：练习次数多的知识点衰减显著更慢，符合"练越多忘越慢"的理论预期。

### 2.4 惰性衰减机制

为避免每次查询都写库，采用**惰性衰减 + 定期固化**双层机制：

- **惰性衰减**（`get_mastery_level`）：实时计算衰减后的值，不写库
- **定期固化**（`apply_decay`）：批量计算并写回，更新 `last_decay_at`

通过 `last_decay_at` 字段记录上次固化时间，衰减窗口为 `max(last_decay_at, last_practiced_at)` 到 `now`，确保不重复衰减。

## 三、答题更新算法

### 3.1 理论依据

**Bloom 掌握学习**（1968）：学生应在掌握当前主题后再进阶。掌握度应随正确练习上升，随错误练习下降。

**BKT 四参数模型**（Corbett & Anderson, 1995）：
- $P(L_0)$：初始掌握概率
- $P(T)$：转移概率（未掌握→掌握）
- $P(G)$：猜对概率（未掌握但答对）
- $P(S)$：滑错概率（掌握但答错）

**Shchepakin et al. (2024)** 指出 BKT 参数需要约束以避免退化。本项目用 `confidence` 参数简化模拟 $P(G)$ 和 $P(S)$。

### 3.2 本项目实现

```python
# 答对：增幅随练习次数递减（越练增幅越小），乘以 confidence
learning_rate = max(0.05, 0.3 * exp(-0.01 * practice_count))
increment = learning_rate * (1 - mastery/100) * confidence
mastery = min(95, mastery + increment)

# 答错：减幅乘以 confidence
decrement = 0.15 * (mastery/100) * confidence
mastery = max(10, mastery - decrement)
```

**confidence 参数**模拟 BKT 的 $P(G)$/$P(S)$：
- `confidence = 1.0`：高置信度（填空/编程/证明题），答对=真掌握
- `confidence = 0.5`：低置信度（选择题），答对可能蒙对，增幅打折
- `confidence = 0.3`：极低置信度（判断题），增幅大幅打折

### 3.3 边界约束

- **下限 10%**：不归零，保留学习可能性（Bloom 理论：所有学生都能达到掌握）
- **上限 95%**：不达到 100%，留有进步空间（Zhang et al. 2025 建议 0.95-0.98）
- **learning_rate 下限 0.05**：防止参数退化（Shchepakin 2024 的约束思想）

## 四、优先级打分算法

### 4.1 理论依据

**Desirable Difficulties**（Bjork, 1994）：适度挑战促进学习。推荐 mastery 在 40-70 范围的知识点（既不太容易也不太难）效果最优。

**过度练习研究**（Zhang et al., 2025, EDM）：过度练习可占练习总量的 58%。mastery > 85 且 practice_count > 10 时应降低优先级。

**认知负荷理论**（Sweller, 1988）：三类负荷（内在/外在/相关）相互独立，教学应最小化外在负荷。

### 4.2 本项目实现

```python
# 基础分：掌握度低(40%) + 权重高(25%) + 时间近(15%)
base = 0.4 * (1 - mastery/100) + 0.25 * weight + 0.15 * time_factor

# 适度挑战加分（desirable difficulties）
if 40 <= mastery <= 70:
    challenge = 0.15        # 适度挑战区间
elif 30 <= mastery < 40 or 70 < mastery <= 80:
    challenge = 0.075       # 边缘区间
else:
    challenge = 0.0         # 太难或太易

# 过度练习惩罚
if mastery > 85 and practice_count > 10:
    penalty = 0.15
else:
    penalty = 0.0

priority = base + challenge - penalty
```

### 4.3 设计决策说明

| 因子 | 权重 | 理论依据 |
|------|------|---------|
| 掌握度低 | 0.40 | Bloom 掌握学习：未掌握的优先补 |
| 考试权重 | 0.25 | 高权重知识点对成绩影响更大 |
| 距期末近 | 0.15 | 期末临近时应试需求上升 |
| 适度挑战 | +0.15 | Bjork 1994：40-70 是最优学习区间 |
| 过度练习 | -0.15 | Zhang et al. 2025：避免浪费 58% 练习量 |

## 五、复习时机预测

### 5.1 理论依据

**间隔重复**（Cepeda et al., 2006）：在"即将遗忘前"进行复习效果最优。过早复习浪费，过晚复习等于重新学习。

**HLR 模型**（Settles & Meeder, 2016）：通过预测回忆概率降到阈值的时间点，安排最优复习时机。

### 5.2 本项目实现

```python
# 当前回忆概率
retention = exp(-days_elapsed / stability)

# 从衰减起点到 retention 降到阈值(0.7)的总天数
total_days = -stability * ln(threshold)

# 从现在开始的剩余天数 = 总天数 - 已过天数
days_until_review = max(0, int(total_days - days_elapsed))

# 当 retention < threshold 时建议立即复习
needs_review = retention < threshold
```

### 5.3 验证结果

| 场景 | 练习次数 | stability(天) | 当前 retention | 需要复习 | 剩余复习天数 |
|------|---------|-------------|---------------|---------|------------|
| 刚练习 | 1 | 15.0 | 1.000 | 否 | 5 |
| 3 天后 | 1 | 15.0 | 0.819 | 否 | 2 |
| 5 天后 | 1 | 15.0 | 0.717 | 否 | 0 |
| 30 天后 | 1 | 15.0 | 0.135 | **是** | 0 |

**结论**：days_until_review 为剩余天数（总天数 - 已过天数），retention 低于 0.7 时正确触发复习提醒。

## 六、前置知识追溯

### 6.1 理论依据

**教育知识图谱**（Aytekin & Saygın, JEDM）：前置关系是 EKG 核心。如果某知识点薄弱，应先检查其前置知识点是否也薄弱。

**ACE 方法**：通过传递性推理（A→B 且 B→C 则 A→C）发现间接前置，BFS 遍历可自动发现多跳依赖。

**因果教育知识图谱**（Sun, 2025）：从"预测学习结果"升级为"解释学习机制"——前置知识薄弱是后续知识点学不好的**因**。

### 6.2 本项目实现

```python
def get_weak_prerequisites(user_id, kp_id, kg_store, mastery_threshold=50.0):
    # 1. BFS 遍历知识图谱获取全部前置知识点
    prereqs = kg_store.get_prerequisites(kp_id, max_depth=5)
    
    # 2. 筛选掌握度低于阈值的
    weak = [p for p in prereqs if get_mastery_level(user_id, p.kp_id) < threshold]
    
    # 3. 按 depth 降序排列（最深层的前置最先补）
    weak.sort(key=lambda x: -x.depth)
```

### 6.3 应用场景

推理引擎决策树：
```
用户请求学习"二叉树遍历"
  → get_weak_prerequisites(user, "二叉树遍历", kg_store)
  → 发现 depth=2 的"线性表"也薄弱
  → 建议先补"线性表" → 再学"递归" → 最后学"二叉树遍历"
```
