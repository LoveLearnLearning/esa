# 课堂上下文分析

## 1. 触发条件
用户请求分析班级整体表现、作业完成情况、教学效果评估或课堂参与度时触发。

## 2. 任务澄清
1. **分析维度**：整体表现/作业分析/参与度/知识掌握/学习趋势
2. **时间范围**：最近一次/本周/本月/整个学期
3. **关注重点**：优秀学生/困难学生/特定知识点/特定作业
4. **输出需求**：数据报告/问题诊断/改进建议

## 3. 授权上下文
1. **班级授权**：检查用户对班级的访问权限
2. **作业授权**：确认可访问的作业范围
3. **学生隐私**：遵守学生隐私保护规范
4. **数据边界**：只分析授权范围内的数据

## 4. 分析框架
### 4.1 整体表现分析
- **成绩分布**：平均分、中位数、标准差、及格率
- **趋势分析**：成绩变化趋势、进步/退步学生
- **对比分析**：班级间对比、历史数据对比

### 4.2 作业分析
- **完成率**：提交率、按时提交率
- **正确率**：各题目正确率、常见错误类型
- **难度分析**：题目难度评估、区分度

### 4.3 知识点掌握
- **掌握度分布**：各知识点掌握情况
- **薄弱环节**：普遍薄弱的知识点
- **个体差异**：不同学生的掌握差异

### 4.4 学习行为分析
- **参与度**：课堂互动、作业提交积极性
- **学习模式**：学习时间分布、学习习惯
- **求助行为**：提问频率、求助内容

## 5. 执行流程
1. 调用 `get_teaching_context` 获取班级和作业上下文
2. 调用 `retrieve_knowledge` 检索教学分析方法
3. 根据分析维度选择分析方法
4. 执行数据分析并生成报告
5. 提供诊断和改进建议

## 6. 输出规范
```text
【分析范围】
班级：[班级名称]
时间：[时间范围]
维度：[分析维度]

【数据概览】
- 学生数：[数量]
- 作业数：[数量]
- 平均分：[分数]

【详细分析】
[各维度的详细分析结果]

【问题诊断】
[识别的主要问题]

【改进建议】
[针对性的改进建议]
```

## 7. 隐私保护
1. **匿名化处理**：群体分析时使用匿名数据
2. **最小必要**：只收集分析必需的数据
3. **访问控制**：严格遵守授权范围
4. **数据安全**：确保数据传输和存储安全

## 8. 禁止事项
- 不得未经授权访问班级数据
- 不得泄露学生个人隐私
- 不得做出歧视性分析
- 不得伪造分析结果
- 不得跳过授权检查
- 不得忽略数据边界
