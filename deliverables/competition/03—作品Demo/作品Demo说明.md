## 三、推荐体验路径

1. 教师账号登录，进入 `教学空间 → 教学工作台 → 演示班级`。
2. 查看已发布诊断作业，打开提交，查看 AI 结构化建议与教师复核入口。
3. 确认 AI 结果不会自动作为正式成绩；由教师修改并主动发布反馈。
4. 学生账号登录，进入 `学习空间 → 作业`，查看本人提交与已发布反馈。
5. 从反馈关联知识点继续进入学习助手或知识地图。
6. 教师返回班级看板，查看只基于已发布反馈形成的知识点聚合。

## 四、演示闭环

```text
教师创建班级并邀请指定学生
→ 学生接受邀请
→ 教师发布带知识点的简答题或代码文本题
→ 学生提交
→ AI 生成结构化分析建议
→ 教师修改、确认并发布
→ 学生查看正式反馈并继续学习
→ 教师查看班级知识点诊断
```

## 五、功能边界

- 当前教学 Demo 的主要题型是简答题和代码文本题。
- AI 不自动决定或发布成绩；教师是最终裁决者。
- RAG、个人知识库、多模态、MCP、LSP 和沙箱受目标环境配置影响。沙箱代码默认关闭。
- `/api/health` 不检查模型、Qdrant、MinerU、邮件或外部网络。
- 当前材料不宣称已在正式课程大规模使用，也不根据小样本试用推断成绩提升。
- 演示数据必须脱敏，不上传真实学号、私人对话、未授权作业或科研数据。

## 六、故障说明

| 现象 | 处理 |
|---|---|
| 页面无法加载 | 检查域名、TLS、Nginx、静态资源与缓存；不要用录好的页面替代实时入口 |
| 登录失败 | 检查临时账号状态和 Session；不要公开密码 |
| 模型超时 | 保留真实错误画面，检查主/辅模型服务与 SSE，不伪造回复 |
| AI 分析不可用 | 教师仍可人工复核；材料中说明辅助模型/服务状态 |
| RAG 无来源 | 说明本次未取得检索证据，使用通用知识或停止引用 |
| 沙箱/LSP 不可用 | 使用编辑与本地补全降级，不宣称代码已在隔离环境执行 |
