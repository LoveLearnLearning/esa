# 教师批改与反馈

## 1. 触发条件
用户请求批改作业、生成反馈、分析学生作答或提供教学建议时触发。

## 2. 任务澄清
1. **批改范围**：单个学生/部分学生/全班
2. **作业类型**：选择题/填空题/解答题/论述题/实践题
3. **反馈需求**：分数/评语/错误分析/改进建议
4. **隐私要求**：匿名化处理/公开反馈/私下反馈

## 3. 隐私保护框架
### 3.1 未发布反馈保护
- **时间边界**：反馈发布前不得向学生透露内容
- **访问控制**：只有授权教师可查看未发布反馈
- **传输安全**：确保反馈内容传输安全
- **存储安全**：未发布反馈加密存储

### 3.2 学生隐私边界
- **最小必要**：只收集批改必需的信息
- **匿名化处理**：群体分析时使用匿名数据
- **访问日志**：记录所有数据访问操作
- **数据保留**：遵守数据保留政策

### 3.3 授权检查
- **教师权限**：确认用户有批改权限
- **班级授权**：确认对班级的访问权限
- **作业授权**：确认对特定作业的访问权限

## 4. 批改流程
### 4.1 自动批改
1. **客观题**：选择题、判断题、填空题自动评分
2. **答案匹配**：精确匹配或模糊匹配
3. **部分给分**：支持部分正确给分

### 4.2 辅助批改
1. **主观题**：解答题、论述题提供批改建议
2. **关键点识别**：识别答案中的关键得分点
3. **错误分类**：分类常见错误类型
4. **评分建议**：提供参考评分和评分理由

### 4.3 反馈生成
1. **个性化反馈**：针对每个学生的具体表现
2. **建设性建议**：提供具体、可操作的改进建议
3. **鼓励性语言**：肯定进步，指出不足
4. **学习指导**：提供后续学习建议

## 5. 执行流程
1. 调用 `get_teaching_context` 获取班级和作业上下文
2. 调用 `retrieve_knowledge` 检索批改标准和反馈方法
3. 执行批改任务（自动或辅助）
4. 生成个性化反馈
5. 遵守隐私保护要求

## 6. 输出规范
```text
【批改范围】
班级：[班级名称]
作业：[作业名称]
学生数：[数量]

【批改结果】
客观题得分：[得分]
主观题评分建议：[评分建议]
总分：[总分]

【反馈内容】
[个性化反馈内容]

【隐私保护】
已遵守隐私保护要求
未发布反馈保护：[保护措施]
学生隐私保护：[保护措施]
```

## 7. 批量处理
1. **进度跟踪**：显示批改进度
2. **错误处理**：处理批改异常
3. **结果导出**：支持导出批改结果
4. **统计报告**：生成班级统计报告

## 8. 禁止事项
- 不得泄露未发布的反馈内容
- 不得未经授权访问学生数据
- 不得做出歧视性评价
- 不得伪造批改结果
- 不得跳过隐私保护检查
- 不得忽略授权边界
- 不得在反馈中使用侮辱性语言
