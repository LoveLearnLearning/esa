# 数据集分析

## 1. 触发条件
用户请求数据分析、统计检验、可视化、机器学习建模、数据清洗或结果解释时触发。

## 2. 任务澄清
1. **分析目标**：描述性统计/推断统计/预测建模/聚类/降维/可视化
2. **数据来源**：用户上传的数据集、已有项目数据、公开数据集
3. **变量说明**：因变量、自变量、控制变量、数据类型
4. **研究问题**：待验证的假设或待探索的问题

## 3. Dataset Authorization
1. **数据权限**：检查用户对数据集的访问权限
2. **隐私边界**：识别敏感字段，遵守数据隐私规范
3. **使用授权**：确认数据使用符合授权范围
4. **项目绑定**：分析任务绑定到当前科研项目

## 4. 分析类型选择
根据研究问题和数据特征选择：
- **描述性统计**：均值、中位数、标准差、分布
- **推断统计**：t检验、方差分析、卡方检验、回归
- **预测建模**：线性回归、逻辑回归、随机森林、神经网络
- **聚类分析**：K-means、层次聚类、DBSCAN
- **降维分析**：PCA、t-SNE、UMAP
- **可视化**：散点图、箱线图、热力图、时间序列图

## 5. 异步 Action 机制
`start_dataset_analysis` 是异步 action，需向用户解释：
1. **审批流程**：action 需要审批后才执行
2. **项目绑定**：分析任务绑定到当前科研项目
3. **数据授权**：需确认数据集访问权限
4. **异步执行**：复杂分析任务在后台完成

## 6. 执行流程
1. 调用 `retrieve_knowledge` 检索相关方法论文献
2. 澄清分析目标和数据特征
3. 选择适当的分析方法
4. 构建分析任务参数
5. 调用 `start_dataset_analysis` 提交分析请求
6. 向用户说明 action 状态和后续步骤

## 7. 输出规范
```text
【分析目标】
研究问题、分析类型、预期产出

【数据说明】
数据来源、变量说明、样本量、数据质量

【方法选择】
分析方法、选择理由、假设检验

【授权确认】
数据权限、隐私边界、项目绑定

【Action 状态】
已提交分析请求，绑定到项目 [project_id]
数据集：[dataset_id]
预计完成时间：[时间]
```

## 8. 结果解释
分析完成后，需解释：
1. **统计显著性**：p值、置信区间
2. **效应大小**：实际意义
3. **局限性**：数据限制、方法假设
4. **后续建议**：进一步分析方向

## 9. 禁止事项
- 不得未经授权访问数据集
- 不得忽略数据隐私边界
- 不得选择不适当的分析方法
- 不得过度解释统计结果
- 不得伪造分析结果
- 未绑定项目时不得提交分析请求
