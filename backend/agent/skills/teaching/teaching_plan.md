# 教学计划设计

## 1. 触发条件
用户请求设计教学计划、课堂活动、课程大纲或教学进度时触发。

## 2. 任务澄清
1. **计划类型**：学期计划/单元计划/课时计划/活动设计
2. **教学内容**：知识点/技能/能力/素养
3. **学生特点**：年级/班级/学习水平/学习风格
4. **时间安排**：课时数/周次/学期进度

## 3. 设计框架
### 3.1 教学目标设计
- **知识目标**：学生需要掌握的知识点
- **技能目标**：学生需要形成的技能
- **能力目标**：学生需要发展的能力
- **素养目标**：学生需要培养的核心素养
- **可测量性**：目标应具体、可测量、可达成

### 3.2 课堂活动设计
- **导入活动**：激发兴趣、联系旧知
- **主体活动**：新知讲解、合作探究、实践应用
- **巩固活动**：练习反馈、总结提升
- **拓展活动**：延伸应用、创新实践
- **时间分配**：各活动时间合理分配

### 3.3 评估设计
- **形成性评估**：课堂观察、提问、练习
- **总结性评估**：作业、测试、项目
- **评估标准**：明确的评估标准和评分细则
- **反馈机制**：及时、具体的反馈

### 3.4 资源准备
- **教学资源**：教材、课件、视频、软件
- **学习资源**：练习册、参考书、网络资源
- **技术工具**：多媒体设备、在线平台

## 4. 执行流程
1. 调用 `get_teaching_context` 获取教学上下文
2. 调用 `retrieve_knowledge` 检索教学资源和方法
3. 分析教学目标和学生特点
4. 设计教学活动和评估方式
5. 制定教学计划和进度安排

## 6. 质量标准
1. **科学性**：符合教育教学规律
2. **针对性**：针对学生实际需求
3. **可行性**：在现有条件下可实施
4. **有效性**：能有效达成教学目标

## 7. 禁止事项
- 不得设计无法实施的教学活动
- 不得忽略学生实际水平
- 不得设置不切实际的教学目标
- 不得跳过评估设计
- 不得忽略资源准备
- 不得违反课程标准
