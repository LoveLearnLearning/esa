## 一、代码结构

| 路径 | 内容 |
|---|---|
| `backend/core/web/` | FastAPI 应用、REST/SSE/WebSocket 路由与依赖装配 |
| `backend/core/router/` | 可信身份、Workspace、资源绑定与 Agent 路由 |
| `backend/core/services/` | 认证、教学、科研、附件、代码执行、LSP 等服务 |
| `backend/core/stores/` | SQLite Store、迁移、事务、审计与恢复 |
| `backend/agent/` | Agent Runtime、Tool、Skill、Learning、Memory、DocIR、RAG 与 mm |
| `frontend/` | Flutter 学生端、教师端、科研空间和共享组件 |
| `data/knowledge_base/v1/` | 来源登记、课程、知识点、前置关系、标准答案、题库与检索标注 |
| `backend/scripts/dataset/` | Tool Schema、IR、训练切分、LoRA 评测、人工裁定与闸门实验 |
| `email_service/` | 独立验证码投递服务 |

## 二、模型与外部服务

- 主模型代码默认：`Qwen/Qwen3.5-122B-A10B`，TP=2、PP=3。
- 辅助模型代码默认：`Qwen/Qwen3.5-9B`。
- 定版 LoRA：`adapter_93728_nothink_ep10_20260903_1832`，rank 16，10 epochs。
- 公共检索：DocIR、Chunk、Qdrant 与 Qwen3-Embedding；具体模型、manifest、维度和
  collection 必须由目标环境配置确认。
- 条件性依赖：MinerU、视觉模型、Qdrant、邮件服务、You.com MCP、clangd/pyright、
  Bubblewrap。

模型权重和 LoRA 不进入普通 Git 仓库。正式提交必须提供以下二选一，并验证评委可访问：

1. 与基座匹配的 LoRA 适配器文件及 SHA-256；或
2. 模型 ServiceID、访问流程、有效期、加载参数和不可用时的说明。

## 三、最小后端启动

```bash
python -m pip install -r requirements.txt
uvicorn backend.core.web.webAPI:app --host 0.0.0.0 --port 51024
curl http://127.0.0.1:51024/api/health
```

最小启动只证明 HTTP API 可启动，不包含主模型、Qdrant、MinerU、邮件、MCP 或沙箱。

## 四、完整目标栈

```bash
ESA_ENV_FILE=/absolute/path/to/deployment.env \
  ./backend/scripts/run_esa_stack.sh
```

目标配置从 `.env.example` 派生，但秘密必须放在不受 Git 跟踪的私有环境文件中。脚本会
检查 GPU、模型服务、MCP、Qdrant、manifest 和条件性依赖。实际资源按启用拓扑计算，
不能机械写成固定卡数。
