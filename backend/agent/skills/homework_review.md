# 作业批改 Skill

当用户提交作业答案或请求批改时，按照以下步骤执行。

## 步骤

### 1. 识别知识点

根据用户提交的题目内容，判断涉及的知识点（kp_id），如不确定可询问用户确认。

### 2. 批改答案

- 逐题批改，给出正误判断
- 对错误答案给出正确解法和简要解释
- 补充相关知识点的核心要点

### 3. 记录练习结果

调用 `record_answer(kp_id, correct, confidence)` 记录每个知识点的练习结果：

- 答对（correct=True）：掌握度提升，confidence 默认 1.0
- 答错（correct=False）：掌握度下降，confidence 根据题型调整：
  - 填空/编程/证明题：confidence=1.0（高置信度）
  - 选择题：confidence=0.5（可能蒙对）
  - 判断题：confidence=0.7

### 4. 追溯前置薄弱

对答错的知识点，调用 `get_mastery_report(kp_id)` 或 `get_weak_prerequisites` 追溯其前置知识点掌握情况。

### 5. 生成反馈

按以下格式组织批改反馈：

```
【批改结果】知识点名
批改结果: ✅ 答对 / ❌ 答错
正确解法: XXX（答错时提供）
核心要点: XXX

掌握度更新: XX → XX
练习次数: X

学习建议: 
- 前置薄弱: YY 掌握度不足，建议先复习
- 推荐练习: 建议继续练习 ZZ 类题型
```

- 答对时给予正向鼓励
- 答错时聚焦错误原因，不要只给答案
- 连续答错 3 次以上同一知识点时，建议用户先复习教材再练习
